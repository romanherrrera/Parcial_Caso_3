# RAÍCES VIVAS — Parcial Diseño Multimedia

Caso 3: Página informativa para un evento cultural.

## Requisitos cubiertos

- Header con nombre del evento.
- Fecha, lugar y descripción.
- Sección de artistas y actividades.
- Formulario de inscripción demostrativo (no funcional).
- Footer con redes/sección de ubicación y mapa conceptual.
- Animaciones fade-in al hacer scroll.
- Diseño responsive.
- Servidor Node.js sin dependencias externas.

## Ejecutar

1. Instalar Node.js.
2. Abrir una terminal en esta carpeta.
3. Ejecutar:

```bash
node server.js
```

4. Abrir `http://localhost:3000`.
